# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `v1` (`main`) | :white_check_mark: |

## Reporting a Vulnerability

We take the security of BDApi4All seriously. If you believe you have found a security vulnerability in this project, please report it to us responsibly.

**Please DO NOT open a public GitHub issue for security vulnerabilities.**

### How to Report

1. Email security details to the maintainer or open a private security advisory on GitHub if enabled.
2. Include:
   - Type of issue (e.g. rate limit bypass, unauthorized admin access, SQL injection)
   - Steps to reproduce
   - Potential impact
3. We will acknowledge receipt within 48 hours and work on a prompt resolution.

Thank you for helping keep BDApi4All secure for everyone!
